# Окончательные договорённости (краткий чеклист)

## Система

- [x] React/TypeScript/Vite + Fastify/Node, SVG engine, ELK.js с доработками — утверждённое направление; допускаются эквиваленты только без потери требований.
- [x] Один Docker-контейнер, SQLite для библиотеки на постоянном томе `/data`.
- [x] Один пользователь, без регистрации; позднее возможно несколько.
- [x] Стиль интерфейса Google Material Design 3/Material You.
- [x] Проекты **НЕ** сохраняются на сервере; только импорт/экспорт JSON-файла, сохранение в браузерной памяти в течение сессии.
- [x] Никакого интерактивного текстового JSON-редактора.

## Библиотека

- [x] Каждому компоненту постоянный уникальный `component_code`; варианты отображения имеют `variant_code`.
- [x] Вариант состоит из 1+ секций `section_id`, все показывать обязательно.
- [x] Секции одной физической микросхемы можно разместить на разных листах.
- [x] Вариант УГО выбирается из БД, строго задан. Нейросеть/сайт не создают/разбивают его автоматически при генерации схемы.
- [x] Ненужные секции нельзя скрыть; их электрическое применение за пределами ответственности сайта.
- [x] Не хранить историю версий компонента; использовать последнее определение, предупреждать о несовместимости.
- [x] Один универсальный шаблон на тип R/C/L с номиналом экземпляра.
- [x] Не вводить электротипы выводов; номер и подпись — да.
- [x] Конструктор расширенных векторных примитивов, поддержка Component JSON.
- [x] Не добавлять компоненты реального диплома пока не запросят.

## Генерация схем

- [x] `tag` сближает элементы; никогда не изображать контуры функциональных групп.
- [x] Mixed layout: автоматически, но приоритет заданных листов/координат, `locked` жёстко.
- [x] Перемещённые вручную объекты записываются в экспортный JSON как зафиксированные.
- [x] Связность электрических цепей не зависит от рисованных проводов; пресечения без узлов не соединять.
- [x] `wire`, `label`, `auto`; специальные УГО питания/земли, межлистовые цепи.
- [x] Повторяемые каскады: каждый физический компонент и секция видны; локальные nets уникальны.
- [x] Листы А3 landscape, рамка ЕСКД, основная надпись и нумерация; SVG каждого листа и ZIP из листов.
- [x] Шрифт GOST Type B; не заявлять соответствие ГОСТ без сверки.
- [x] Никакого UI для редактирования ГОСТ-оформления: пользователь даст образец, ассистент поправит **код**.

## Документация

- [x] `SCHEMATIC_AI.md` — инструкция внешней нейросети.
- [x] `COMPONENT_BUILDER_AI.md` — инструкция внешней нейросети по конструктору.
- [x] `COMPONENT_CATALOG.md` — **автоматически** из текущей БД с кодами/подкодами/секциями/номерами физических выводов.
