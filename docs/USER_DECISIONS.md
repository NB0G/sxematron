# Уточнения владельца от 20.10.2026

Имеют приоритет над переданным архивом ТЗ.

- Контрольный масштаб: 500 физических компонентов, 1000 цепей, 20 листов.
- Добавление компонентов из библиотеки в редактор обязательно; разработчику не нужно вручную собирать схемы для пользователя.
- Позиционные обозначения сохраняются; новые получают свободные номера, перенумерация отдельной командой.
- Удалены назначения выводов: нет имён, функций и электрических типов. Физические номера, принадлежность секциям и геометрия сохранены. Именованные цепи и роль питания у цепи сохранены.
- Конфликты импорта библиотеки разработчик разрешает разумным способом: предварительная проверка и явная замена отличающихся записей, без изменения кодов.
- Полное сенсорное управление не требуется.
- Отдельный Docker-проект для Intel x86-64; ориентир 2 CPU и 2 ГиБ RAM, допускается больше ресурсов.
- Автономная работа после установки, без внешних ресурсов.
- Результат предназначен для печати SVG на А3. Экспорт с контурами шрифта по умолчанию.
- Передача полного архива; Git и внешняя публикация не нужны.

Остальные обязательные решения исходного ТЗ сохранены. Исходное ТЗ лежит в `docs/original/`, этот документ определяет поздние уточнения.
