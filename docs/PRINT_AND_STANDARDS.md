# Печать А3, шрифт и нормативная проверка

## Как печатать

1. Экспортировать SVG для печати с текстом в контурах. Этот вариант исключает
   подмену шрифта на компьютере или драйвере принтера.
2. В программе печати выбрать бумагу **А3, 420 × 297 мм, альбомная ориентация**.
3. Выбрать **100% / фактический размер**, отключить «вписать», «подогнать»,
   «уменьшить большие страницы» и автоматический поворот.
4. Отключить колонтитулы браузера. Проверить предпросмотр: рамка и основная
   надпись должны целиком попадать в печатную область принтера.
5. При сомнениях измерить на пробном отпечатке известный отрезок. Масштаб
   может изменяться именно программой печати или драйвером, даже если SVG
   имеет правильные размеры.

Каждый SVG задаёт физические размеры `width="420mm" height="297mm"` и
`viewBox="0 0 420 297"`. Одна единица чертежа соответствует миллиметру.
Сетка, выделение, цветные маркеры редактора в экспорт не входят.

Редактируемый SVG сохраняет `<text>` и использует локальный OpenGOST type B.
Для максимальной переносимости печатного результата следует выбирать
вариант с контурами: внешние SVG-обработчики неодинаково поддерживают
встроенные шрифты. Оба варианта остаются векторными.

## Шрифт

В `assets/fonts/` поставляется настоящий открытый чертёжный **OpenGOST type B
Regular**, не подмена обычным системным шрифтом. Кириллица, латиница и цифры
доступны локально. Интернет приложению для шрифта не нужен.

Файл TTF из релиза OpenGOST 0.7 распространяется по SIL OFL 1.1;
лицензия, авторство, источник и контрольная сумма приведены в
`assets/fonts/PROVENANCE.md`, `LICENSE.txt` и `FONTLOG.txt`.
Неподдерживаемые выбранным шрифтом символы при переводе в контуры вызывают
понятную ошибку вместо молчаливой потери букв.

Преобразование в контуры реализовано общей функцией `outlineSvgText` в
`packages/core/src/font.ts`. Она работает в браузере и Node.js, сохраняет
координаты, выравнивание и преобразования из общего рендерера. Загружаемый
пользователем произвольный SVG не является входным форматом конструктора.

## Граница проверки

А3, миллиметровая геометрия, единый векторный рендерер и локальный Type B
реализуются программно. Полная проверка рамки, всех граф основной надписи,
обозначений разнесённых секций, адресации межлистовых продолжений и каждого
библиотечного УГО требует сверки с полными применимыми текстами стандартов и
точными образцами пользователя. До этой сверки приложение **не следует
объявлять полностью ГОСТ-аттестованным**.

Правила меняются в исходном коде и регрессионных тестах; редактора
ГОСТ-оформления в пользовательском интерфейсе нет. Стартовые синтетические
компоненты служат проверке алгоритмов и не являются готовой библиотекой
реального дипломного устройства.

## Физическая высота букв

У включённого OpenGOST Type B em равен 1700 единицам, высота прописной Н — 1000. Рендерер применяет коэффициент 1,7 к SVG font-size: заданная высота 3,5 мм действительно даёт прописную букву высотой 3,5 мм, а не 2,06 мм. Это проверено числовым тестом. Для номеров выводов используется высота 2,5 мм.
