# OpenGOST type B — происхождение и лицензия

В поставке находится неизменённый `OpenGOSTtypeB-Regular.ttf` из релиза
[OpenGOST TTF 0.7](https://github.com/ingenium-am/open-gost-arm/releases/tag/v0.7).
Локальное имя файла: `OpenGOSTTypeB-Regular.ttf` (переименован только файл,
внутренние таблицы шрифта не изменялись).

Источник архива:
https://github.com/ingenium-am/open-gost-arm/releases/download/v0.7/OpenGOST_TTF_0.7.zip

Исходный проект:
https://github.com/ingenium-am/open-gost-arm

Лицензия: SIL Open Font License 1.1; полный неизменённый текст приложен в
`LICENSE.txt`, история шрифта — `FONTLOG.txt`. Семейство внутри TTF —
`OpenGOST type B`, начертание Regular, 633 глифа. Исходные латинские,
кириллические и греческие наборы разработаны Никитой Волченковым;
расширение армянским набором — Левоном Меликяном. Авторство и условия
определяются приложенной лицензией и FONTLOG, а не данным пересказом.

SHA-256 поставляемого файла:
`8307a636e921a3be10d36034581caafd8cf36cb85909b8add21d22f71fcde1f8`

OFL разрешает включение шрифта в приложение, встраивание и распространение
вместе с лицензией. Зарезервированные имена нельзя присваивать изменённому
производному шрифту без отдельного разрешения. В этом проекте шрифт не
изменяется. SVG с контурами не требует установки шрифта на компьютере печати.

Проверено программно наличие кириллицы (включая Ё/ё), цифр, латинских
позиционных обозначений и символов `± µ Ω −`. Наличие шрифта Type B само по
себе не является сертификацией всего чертежа по ЕСКД.
