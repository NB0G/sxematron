## Проверенные сценарии

- Схема загружается из JSON с проверкой кодов, вариантов, секций и физических номеров выводов.
- Все обязательные секции одной микросхемы показываются на двух листах с одним физическим экземпляром и общим обозначением.
- Перетаскивание мышью сохраняет точные фиксированные координаты в скачанном JSON; undo восстанавливает позицию.
- Ручные провода остаются ортогональными, сохраняют конечные контакты и переживают повторный импорт JSON.
- Проверяется связность закреплённых проводов: раздельные фрагменты, лишь касающиеся разных контактов, не считаются соединением.
- Ошибочный импорт не заменяет текущую схему.
- В схему добавляются компоненты библиотеки, создаются цепи по физическим номерам.
- Конструктор импортирует Component JSON, позволяет дорисовать фигуру мышью и сохранить определение в SQLite.
- Изменения библиотеки немедленно видны в генерируемом каталоге.
- CRUD, резервирование удалённых кодов, транзакционный импорт, консистентный backup, повторный запуск и отсутствие серверного хранилища проектов проверены API-тестами.
- Повторяемые каскады материализуются с уникальными ID/локальными цепями и явно общими портами.
- Геометрические пересечения разных цепей не превращаются в электрический узел.
- Одинаковые входные данные дают одинаковые позиции, маршруты, SVG и ZIP; ZIP использует фиксированные timestamps.
- Примитивы ограничены белым списком, текст XML-экранируется, координаты конечны, глубина и размер JSON ограничены. Статические валидаторы работают при запрещённой генерации кода.

## Нагрузка

Последнее измерение записано в benchmark.json. Оно выполнено на доступном процессоре среды, **без Docker-ограничения 2 CPU**, и не является обещанием времени на конкретном сервере.

| Сценарий | Время | RSS после сценария | Результат |
|---|---:|---:|---|
| 500 компонентов, 1000 цепей-меток, 20 листов, координаты автоматические | **1,46 с** | **235 МиБ** | 500 секций, 2000 меток, без ошибок/предупреждений |
| Плотный граф: 100 компонентов, 200 auto-цепей, 4 листа | **0,34 с** | **325 МиБ** | 72 непроходимых ветви заменены именованными метками с предупреждениями; электрическая модель сохранена |

Размещение учитывает место под надписи и именованные метки; диагностика проверяет их наложения и выход за рамку. При принудительном wire невозможность трассировки блокирует экспорт. Для произвольного графа удобство рисунка не гарантируется: остаются ручная правка и явный выбор wire/label/auto.

## Печать

В verification лежат реальные итоговые SVG, ZIP и нормализованные JSON примеров demo, auto и repeated. print-sheet-1.png — растровый контрольный просмотр **векторного** файла demo_sheet_01.svg; исходный SVG не растрирован. Его геометрия сверена с tests/golden/demo-sheet-1.svg.

Размер каждого экспортированного листа — width=420mm, height=297mm, viewBox="0 0 420 297". По умолчанию буквы переведены в контуры; вариант с редактируемым текстом включает font-face с локальным шрифтом внутри SVG. OpenGOST Type B распространяется по OFL 1.1. Числовой тест проверяет реальную высоту прописной буквы 3,5 мм, с учётом метрик font em.

## Что нельзя считать подтверждённым

Сам контейнер не запускался, поскольку Docker здесь отсутствует. Dockerfile выполняет полный npm run check перед упаковкой, Compose содержит volume /data и лимиты, а scripts/docker-smoke.sh предназначен для повторяемой проверки на машине с Docker. Рабочий production-сервер и браузер проверены напрямую на Node 24. Готовый image.tar в архив не входит.

Рамка/штамп и межлистовые подписи реализованы, однако это не заключение о полном соответствии всем применимым ГОСТ. Геометрия основной надписи, оформление разнесённых частей и адресация продолжений должны пройти окончательную визуальную сверку по эталонам владельца. Изменять для этого нужно geometry.ts/render.ts/font.ts и golden-тесты, пользовательского настройщика ГОСТ нет.

Не реализованы исключённые из объёма функции: серверное хранение проектов, аккаунты, многопользовательский доступ, электрические типы/назначения выводов, ERC, реальная дипломная библиотека, полное сенсорное управление. Шаблоны повторов вводятся через JSON; отдельного визуального редактора шаблонов нет.

Сборщик предупреждает о размере единого JS-бандла (~2,5 МБ до gzip, ~0,76 МБ gzip), поскольку включены ELK, Material UI, статические схемы и шрифт. Это предупреждение о размере, а не ошибка сборки; runtime использует только локальные файлы.
